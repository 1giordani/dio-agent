# Entrega na DIO

Link do repositório público: https://github.com/1giordani/dio-agent

## Descrição para a submissão
Especialização do DIO Agent como mentor de AppSec, com skill de análise de vulnerabilidades, base de conhecimento e persona defensiva. Inclui laboratório local de SQL Injection, correção com consultas parametrizadas, testes de regressão e modelo padronizado de relatório com contexto, evidências, impacto, probabilidade, severidade e reteste. Os testes Python foram executados; a avaliação conversacional no Hermes possui roteiro documentado e ainda precisa ser realizada.

O projeto evolui a base digitalinnovationone/dio-agent e preserva as contribuições anteriores. Aulas e sessões do Hermes não são marcadas como concluídas por esta entrega.
