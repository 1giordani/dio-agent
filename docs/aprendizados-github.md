# Aprendizados sobre colaboração no GitHub

Este documento registra a prática realizada por **Giordani Martins Silva** no desafio **Explorando Colaboração e Markdown**, da Formação GitHub Certification — DIO.

## Conceitos praticados

### Fork

O fork cria uma cópia de um repositório na conta do usuário e mantém a referência ao projeto original. Assim, é possível experimentar e documentar melhorias sem alterar diretamente a fonte.

### Branch

A branch cria uma linha separada de trabalho. A alteração deste documento foi desenvolvida em `docs/aprendizados-github`, mantendo a branch `main` estável.

### Commit

O commit registra uma alteração no histórico do repositório. Uma mensagem clara explica o propósito da mudança.

### Issue

A issue organiza uma tarefa, dúvida, sugestão ou problema que precisa ser acompanhado.

### Pull request

O pull request propõe a integração de mudanças de uma branch para outra e permite revisar o conteúdo antes do merge.

## Fluxo utilizado

```text
Repositório original
        ↓
       Fork
        ↓
Branch de documentação
        ↓
      Commit
        ↓
  Pull request
        ↓
      Revisão
        ↓
       Merge
```

## Conclusão

A atividade demonstrou que o GitHub não serve apenas para armazenar arquivos: ele também organiza o histórico, a revisão e a colaboração em projetos.
