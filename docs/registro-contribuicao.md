# Registro da contribuição

Este documento registra a prática de colaboração realizada por **Giordani Martins Silva** durante a Formação GitHub Certification da DIO.

## Fluxo executado

1. Criação do fork do projeto original;
2. Personalização do README;
3. Abertura da issue [#3](https://github.com/1giordani/dio-agent/issues/3);
4. Criação da branch `docs/registrar-experiencia-dio`;
5. Atualização da documentação;
6. Abertura e conclusão de pull request.

## Aprendizados

A atividade permitiu praticar a separação de alterações por branch, o registro do objetivo em uma issue, a revisão por pull request e a integração segura das mudanças à branch principal.
